#### Bookmark

3. scrivi `javascript:(function () {let code = document.createElement('script');code.src = 'https://github.com/LibreScore/dl-librescore/releases/latest/download/dl-librescore.user.js';document.body.appendChild(code);}())` nel campo URL
4. salva il preferito
5. Quando Sei su Muse Score con lo spartito aperto clicca sul preferito per attivare Il download
